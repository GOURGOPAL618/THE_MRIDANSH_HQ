Version: 1.0

This document defines the permanent engineering rules of the MRIDANSH Headquarters.

These rules must always be followed.

MRIDANSH Headquarters is not a normal website.

It is a private aerospace-inspired mission control system.

Every feature must serve a real purpose.

No unnecessary pages.

No unnecessary buttons.

No unnecessary animations.

No unnecessary complexity.
