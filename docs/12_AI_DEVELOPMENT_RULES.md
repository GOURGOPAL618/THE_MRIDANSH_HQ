# AI DEVELOPMENT RULES

Every coding task must follow these rules.

1. Read all relevant documents inside /docs before generating code.

2. Never assume requirements.

3. Never modify unrelated files.

4. Never remove existing functionality without permission.

5. Keep components modular.

6. Keep code production-ready.

7. Explain important implementation decisions.

8. If a requirement is ambiguous, ask instead of guessing.

9. Prefer readability over cleverness.

10. Do not introduce unnecessary dependencies.

11. Optimize only where it matters.

12. Write code as if the project will be maintained for 10 years.
