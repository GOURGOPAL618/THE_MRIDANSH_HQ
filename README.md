### 🧠 AI Command Center

The **JCC AI Core** provides context-aware intelligent assistance across mission domains.

**Supported AI Modes**

| Mode | Function |
|---|---|
| 🧾 Logs Analyzer | Parses & summarizes system activity logs |
| 🔬 Research Abstractor | Extracts insight from research documents |

### 🛡️ Security Architecture

Security is treated as a **core system layer**, not an afterthought.

- 🔐 JWT-based authentication
- 🍪 HttpOnly cookie authentication
- 🛡️ Security headers middleware
- 🚫 Content Security Policy
- 🧱 X-Frame-Options protection
- 🧪 X-Content-Type-Options protection
- 🔒 Referrer Policy enforcement
- 🔥 HTTPS-aware HSTS
- 🚦 Client IP-based API rate limiting
- 🧾 Security event logging
- 🔑 Environment-based secret management
- 🧹 Sanitized production error responses

**Rate Limits**

| Endpoint | Limit |
|---|---|
| Authentication Login | 5 req/min/IP |
| AI Query & Stream | 10 req/min/IP |
| General API | 100 req/min/IP |
| Liveness Checks | Exempt |

## 🚀 Local Development

### Clone Repository
```bash
git clone <your-repository-url>
cd THE_MRIDANSH_HQ
```

### Backend Setup
```bash
cd backend
python -m venv .venv

# Activate (Windows)
.venv\Scripts\activate

pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

Frontend available at → `http://localhost:3000`

---

## 🔐 Environment Configuration

Create a `.env` file based on `.env.example`. **Never commit secrets to Git.**

```env
DATABASE_URL=sqlite:///./mridansh.db
JWT_SECRET_KEY=replace_with_secure_secret

NASA_API_KEY=
OPENAI_API_KEY=
GOOGLE_API_KEY=
OPENWEATHER_API_KEY=
GITHUB_API_KEY=
```

## 🧪 Running Tests

**Backend** (from project root)
```bash
.\backend\.venv\Scripts\python tests/run_backend_tests.py
```

**Frontend**
```bash
npm test --prefix frontend
```

**Production Build**
```bash
npm run build --prefix frontend
```

## 🐳 Docker Deployment

```bash
docker build -f backend/Dockerfile -t the-mridansh-hq-backend .
docker run -p 8000:8000 the-mridansh-hq-backend
```

> The container entrypoint automatically runs database migrations before launching the ASGI server.
